# 质量基线

## 范围

- 日期：2026-08-08（Asia/Shanghai）
- 浏览器：Microsoft Edge / Chromium
- 桌面视口：1440 x 960
- 移动视口：390 x 844
- 页面：暗室、柳永、苏轼、王维、长卷

检查包含页面加载、JavaScript 异常、控制台错误、文档宽度、基础语义和 axe 自动化可访问性扫描。它是后续改造的对照组，不是“已经完全无障碍”的证明。

## 内容完整度

五篇并非同一成熟度：

- 苏轼页已有章节化长文，是当前内容骨架的主要参考。
- 柳永与王维页具有人物叙事结构，但正文密度和资料支撑仍不足。
- 暗室与长卷属于空间/滚动叙事实验，不应被强行套入人物传记模板。
- 当前页面没有形成统一的来源、校勘、编辑说明和版本记录。
