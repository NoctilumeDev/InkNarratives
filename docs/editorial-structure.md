# 编辑骨架

## 两类页面

仓库中的页面应先按表达目标分型，避免为了“统一”把不同作品改成同一种长页面。

### 人物长文

适用于苏轼、柳永、王维：

1. 封面与一句准确定位
2. 人物身份、时代与关键时间线
3. 分阶段生平，而不是事件堆叠
4. 代表作品及其创作语境
5. 地理迁徙与重要关系
6. 文学影响、争议与后世接受
7. 引文归属、资料来源与编辑说明
8. 页面版本与最后核验日期

### 空间叙事

适用于暗室、长卷：

1. 明确单一体验命题
2. 场景之间具有可解释的推进关系
3. 每一段动效都服务于阅读或空间感，而不是展示技术数量
4. 静止状态、减少动效状态和移动端仍能完整表达内容
5. 结尾对开头形成回应，不以无目的的无限滚动收场

## 共享边界

可以共享的是质量标准、排版尺度、可访问性约束和资料规范；不应过早共享的是颜色、纸张纹理、转场方式和页面组件。先让每个作品找到自己的视觉语法，再从真实重复中提取公共层。
