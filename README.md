# InkNarratives / 墨叙

中文文学主题的交互叙事前端实验集。仓库收录五个零依赖、单文件 HTML Demo，用于探索长文编排、滚动叙事、氛围动效与中文网页的视觉表达。

> **Status: Prototype.** 这些页面是可运行的设计实验，不是组件库、生产模板或经过学术校勘的数字人文成果。

## 定位

- 中文标题、正文和界面文案是作品本身的一部分，不需要改成英文。
- 每个 Demo 都可直接在现代浏览器中打开，无需安装依赖或启动开发服务器。
- 当前保留单文件结构，便于独立观察每一种视觉语言；后续只有在共享代码真正形成时才抽取公共层。
- 人物生平与作品内容仍需补齐资料来源、编辑说明和事实核验，不能将视觉完整度等同于内容可靠性。

## 运行

直接打开任意 `.html` 文件即可。若浏览器限制本地文件能力，可在仓库目录启动任意静态文件服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。仓库当前没有统一入口页，也暂未启用 GitHub Pages；等整体视觉与文章骨架稳定后再发布在线展厅。

## 质量边界

2026-08-08 已使用 Microsoft Edge 对五个页面执行桌面端 `1440x960` 与移动端 `390x844` 检查：

- 10 个页面/视口组合均无 JavaScript 异常和控制台错误；
- 五个移动端页面均无横向溢出；
- 首次入库前已修复 `柳永.html` 的 ARIA 与标题层级问题；桌面固定雾层仍会让文档宽度多出 16px，留待视觉阶段处理；
- `长卷.html` 的显影状态存在自动化对比度告警；
- 自动化结果不能替代键盘、屏幕阅读器、动效舒适度和内容事实的人工验收。

完整记录见 [质量基线](./docs/quality-baseline.md)，后续文章结构见 [编辑骨架](./docs/editorial-structure.md)。

## 文件名与公开 URL

Git、GitHub 和现代浏览器均支持 UTF-8 中文文件名，现有文件可以继续使用中文。中文路径在公开 URL 中会被百分号编码，因此正式启用 Pages 时，建议使用稳定的英文目录作为 URL，例如 `demos/sushi/`，页面标题与正文仍保留中文。
